# ✨ LUXORA

### Premium Full-Stack E-Commerce Platform

**LUXORA** is a modern full-stack e-commerce platform built with **React and FastAPI**, designed with a premium shopping experience and a complete end-to-end commerce workflow.

It demonstrates practical skills in **frontend engineering, REST API development, authentication, database management, secure payments workflow, email automation, and cloud deployment**.

---

## ✨ Key Features

* 🛍️ **Product Discovery** — Browse products with search, filtering, product details, quick view, and reviews.
* 🛒 **Smart Shopping Cart** — Add, remove, update quantities, and manage cart items seamlessly.
* ❤️ **Wishlist** — Save and manage favorite products.
* 🔐 **Authentication & Security** — User registration, login, protected routes, password hashing, JWT-based authentication, and password reset with OTP email verification.
* 📦 **Complete Order Management** — Checkout, order creation, order history, order details, status tracking, and delivery information.
* 💳 **Multiple Payment Methods** — Cash on Delivery, UPI, and Credit/Debit Card payment workflows.
* 🧾 **Automated Receipts** — Generates a detailed order receipt after successful confirmation.
* 📧 **Email Automation** — Sends order confirmation and receipt directly to the customer's registered email using secure SMTP configuration.
* 📍 **Address Management** — Save and manage delivery addresses.
* ⭐ **Product Reviews** — Customer review and rating functionality.
* 📱 **Responsive UI** — Premium, responsive shopping experience across devices.
* ⚡ **RESTful Backend** — Structured FastAPI APIs with separated routers and service layers.
* 🗄️ **Database Integration** — SQLAlchemy-powered persistence for users, products, carts, orders, addresses, reviews, and related data.
* ☁️ **Cloud Deployment** — Independently deployed frontend and backend with production environment configuration.

## 🔄 Core Architecture

```text
React Frontend
      ↓
REST API
      ↓
FastAPI Backend
      ↓
SQLAlchemy / Database
      ↓
Order & Authentication Services
      ↓
SMTP Email Service
      ↓
Customer Receipt
```
